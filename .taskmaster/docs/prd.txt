# Chat-AI Project - Product Requirements Document

## Project Overview
Chat-AI is a comprehensive AI-powered chatbot application built with Next.js 15, React 19, and the Vercel AI SDK. The application provides a modern, feature-rich chat interface with MCP (Model Context Protocol) integration, allowing users to interact with various AI models and external tools seamlessly.

## Core Features

### 1. Multi-Provider AI Chat Interface
- Support for multiple AI providers: OpenAI, Anthropic (Claude), Google Gemini, xAI, OpenRouter, Ollama
- Real-time chat with streaming responses
- Voice assistant capabilities with OpenAI Realtime API
- Model switching and provider management
- Custom system prompts and chat customization

### 2. MCP (Model Context Protocol) Integration
- Seamless integration with external MCP servers
- Tool mentions (@toolname) for quick tool access
- Visual workflow creation and management
- Custom tool presets and configurations
- Browser automation with Playwright MCP
- Web search capabilities with Exa AI

### 3. Authentication & User Management
- Better Auth integration with OAuth providers (Google, GitHub, Microsoft)
- User session management
- Secure authentication flows
- User preferences and settings

### 4. Database & Data Management
- PostgreSQL integration with Drizzle ORM
- User data persistence
- Chat history and conversation management
- Database migrations and schema management

### 5. Advanced UI/UX Features
- Modern, responsive design with Tailwind CSS
- Dark/light theme support
- Interactive data visualization tools
- Export capabilities (CSV, Excel)
- Real-time collaboration features
- Temporary chat windows

### 6. Development & Deployment
- Docker containerization support
- Vercel deployment ready
- Comprehensive testing suite (Vitest, Playwright)
- CI/CD pipeline integration
- Environment configuration management

## Technical Architecture

### Frontend Stack
- Next.js 15 with App Router
- React 19 with TypeScript
- Tailwind CSS v4 + shadcn/ui + Radix UI
- Framer Motion for animations
- Zustand for state management

### Backend Stack
- Next.js API routes
- Better Auth for authentication
- Drizzle ORM with PostgreSQL
- AI SDK v4 for LLM integration
- MCP SDK for tool integration

### Development Tools
- Biome for linting and formatting
- Husky for git hooks
- Playwright for E2E testing
- Vitest for unit testing
- TypeScript strict mode
